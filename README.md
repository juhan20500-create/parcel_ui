# 우체국 접수 목록 (parcel_ui)

포도 농장 택배를 우체국 **창구소포 파일접수** 양식(.xls)으로 만들어 주는 로컬 웹앱.

## 다른 컴퓨터에서 쓰기

```bash
git clone https://github.com/juhan20500-create/parcel_ui.git
cd parcel_ui
```

- **맥**: 폴더 안의 `실행.command`를 두 번 누른다. 처음 한 번은 필요한 것들을 자동으로 받는다.
- **윈도우 / 직접 실행**:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt   # 윈도우는 .venv\Scripts\pip
.venv/bin/python parcel_app.py
```

브라우저에서 http://localhost:5063 이 열린다.

## 쓰는 법

1. 보내는 손님 이름을 넣는다(안 적으면 접수는 `시골농원` 이름으로 나간다). 전화칸은 비워도 된다.
   손님 이름을 적으면 받는 분 이름 뒤에 `OOO보냄`이 붙는다.
2. 받는 분을 넣고 `주소찾기`로 우편번호·주소를 채운다.
3. 상자 개수(3kg / 5kg)를 넣고 `목록에 추가`.
4. 아래 `xls 내보내기` → 다운로드 폴더에 파일 하나. 상자 종류(청향→캠벨, 작은 상자→큰 상자) 순으로 정렬돼 나간다.
5. 오른쪽 위 `우체국 사이트`에서 창구소포 간편사전접수 → `주소(파일) 이용하기`로 그 파일을 올린다.
6. 창구에 내고 나면 `접수 끝냄`으로 목록을 기록으로 옮긴다.

## 상자 묶는 규칙

| 넣은 상자 | 접수 중량 |
|---|---|
| 3kg 1개 | 5kg |
| 3kg 2개 | 7kg |
| 5kg 1개 | 7kg |
| 5kg 2개 | 15kg |

3kg 3개면 7kg + 5kg 두 건이 된다. 내용품코드 `농/수/축산물(일반)`, 부피 `80`은 자동으로 들어간다.

받는 분 이름 뒤에는 `OOO보냄`이 붙는다(보내는 분이 시골농원이면 안 붙는다).

## 저장되는 곳

`storage/` 폴더에 접수 목록·주소록·지난 기록이 들어간다. **손님 개인정보라 깃에 올리지 않는다**
(`.gitignore`에 넣어 뒀다). 컴퓨터를 옮길 때 기록도 옮기려면 `storage/` 폴더를 직접 복사한다.

## 다른 컴퓨터로 옮길 때

코드는 깃으로 받으면 되지만 **접수 목록·주소록·지난 기록은 깃에 없다**(`storage/`는 손님 개인정보라 제외).
그 자료까지 옮기려면 `storage/` 폴더를 USB나 에어드롭으로 직접 복사해 같은 자리에 둔다.
